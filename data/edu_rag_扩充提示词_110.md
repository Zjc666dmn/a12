# 教育 RAG 知识库扩充 · 110 个文档主题化生成提示词

用法：把每条提示词单独发给大模型，得到一个 JSON 对象。把 110 个 JSON 保存为 `doc_1.json` … `doc_110.json`（以文档 id 命名）发回给我，我会校验字段并批量写入 `chunks / knowledge_points / questions / knowledge_point_chunks` 等表。

统一约定：新增文本块 embedding_status 会置为 pending，便于后续重新向量化；不改表结构、不动已有数据。
