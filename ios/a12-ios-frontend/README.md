# A12 教学智能体演示系统

这是一个面向 A12「多模态 AI 互动式教学智能体」比赛演示的移动端前端。页面采用浅色 Studio 工作台风格，按真实教师备课流程组织：输入教学需求、上传资料、追踪 Pi Agent 生成过程，并导出 PPT 课件、Word 教案和课堂互动方案。

## 打开方式

直接用浏览器打开 `index.html` 即可。

## 已覆盖的核心界面

- 首页创建入口：产物类型选择、教学需求输入、语音/上传入口、启动生成。
- Studio 工作台：对话、预览、文件三个标签页。
- 底部导航：首页、项目、知识库、我的均可切换。
- 首页产物类型：课件 PPT、Word 教案、互动小游戏、课堂动画均可点击切换，并同步改写需求输入框。
- 语音按钮：模拟语音识别并填入文本。
- 上传按钮：打开本地文件选择，选择后进入文件页并显示上传资料。
- 修改按钮：追加用户修改意见和智能体回复，更新生成状态，并自动切换到预览页。
- Pi Agent 状态：展示后端智能体运行状态。
- A12 任务流程：需求结构化、RAG 检索、资料解析、PPT/Word/小游戏生成。
- 导出入口：下载已预生成的真实 `.pptx`、`.docx` 和 HTML5 小游戏文件。
- 右侧 Studio 工作台：课件、教案、小游戏、知识库、全部分类均可点击切换；加号、发送按钮和示例产物卡片均有即时反馈。
- 课件样例：`AI_导论课件.pptx`，共 12 页，采用原生 PPT 文本与形状对象，便于后续在 WPS/PowerPoint 里继续编辑。
- 课件预览：`AI_导论课件_预览总览.jpg`。
- 教案样例：`AI_导论教案.docx`，共 2 页，包含课程信息、教学目标、学情分析、流程安排、互动设计、评价方式和课后作业。
- 视觉呈现：macOS 窗口容器、轻网格背景、胶囊式产物分类、极简输入框和示例产物卡片。

## 后续接后端建议

- 首页 composer 对接 Pi Agent 的需求理解接口。
- 上传按钮对接 PDF、Word、PPT、图片、视频上传接口。
- Studio 对话页接 SSE/WebSocket 流式输出。
- 预览页接 PPT 缩略图、Word 教案摘要和 HTML5 互动内容。
- 文件页接本地知识库、参考资料和生成产物列表。
- 当前演示版已内置可下载的 Office 样例文件；正式版本建议由 Pi Agent 后端按教师需求动态生成 `.pptx/.docx`。
